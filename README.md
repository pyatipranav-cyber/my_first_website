# Niyaaz website concept (flat, static, Vercel-ready)
Files: index.html, admin.html, style.css, app.js, menu.js, vercel.json, README.md
Deploy: push all files to the repo root on GitHub, import in Vercel, framework "Other", no build command.
Edit menu.js: real prices, real WhatsApp number (WA), real outlet list.
NOT a clone of niyaaz.in. The live site could not be read by the tool; see chat notes.
Demo limits: orders, rewards and the console use browser localStorage only. Production needs auth + DB (Supabase), Razorpay, and server-side validation.
Prices in menu.js are placeholders.
